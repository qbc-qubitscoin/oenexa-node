Cryptography

POST-QUANTUM
ML-DSA-65
Module Lattice-based Digital Signature Algorithm (FIPS 204). Resistant to attacks from large-scale quantum computers. Security level 3 — equivalent to AES-192.
STATE TREE
Sparse Merkle Trie
Efficient key-value authenticated data structure for account/contract state. Enables compact Merkle proofs without storing empty leaves, supporting fast light-client verification.
HASH
SHA-3 / SHAKE-256
All block and transaction hashes use SHA-3 (Keccak family). Quantum-resistant one-way function for integrity proofs and Merkle leaf construction.
